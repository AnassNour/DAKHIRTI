# DAKHIRTI Web — تطبيق مالي تعليمي بـ Python

## الخصائص
- واجهة ويب متجاوبة للهاتف والحاسوب باستخدام Streamlit.
- دعم الفرنسية والعربية (تبديل اللغة من الشريط الجانبي).
- إنشاء حساب وتسجيل الدخول.
- تخزين كلمات المرور باستخدام PBKDF2-HMAC-SHA256 مع salt.
- رصيد افتراضي تجريبي بقيمة 1000 درهم لكل حساب جديد.
- تحويل افتراضي بين مستخدمين مسجلين في قاعدة البيانات المحلية نفسها.
- إضافة وسحب رصيد تجريبي.
- أهداف توفير ومساهمات مع شريط تقدم.
- تسجيل المداخيل والمصاريف حسب الفئة.
- سجل العمليات مع التصفية.
- إحصائيات ورسوم بيانية باستخدام Plotly.
- قاعدة بيانات SQLite محلية.

## التشغيل
1. ثبّت Python 3.10 أو أحدث.
2. فك ضغط المشروع وافتح Terminal داخل مجلد DAKHIRTI_WEB.
3. ثبّت المكتبات:
   `pip install -r requirements.txt`
4. شغّل التطبيق:
   `streamlit run app.py`
5. افتح الرابط المحلي الذي يظهر في الطرفية. غالباً:
   `http://localhost:8501`

## تجربة التحويل
- افتح التطبيق في متصفحين أو نافذتين.
- أنشئ حسابين مختلفين.
- سجل الدخول بالحساب الأول وحوّل مبلغاً إلى اسم الحساب الثاني بالضبط.
- سجل الدخول بالحساب الثاني وسترى التحويل في الرصيد وسجل العمليات.

## النشر على الإنترنت
يمكن نشر المشروع على خدمة تستضيف تطبيقات Streamlit أو على خادم خاص.
عند النشر، لا تعتمد على SQLite المحلية للتعامل مع عدة نسخ/خوادم؛ استخدم قاعدة بيانات خادمية مناسبة، وأضف HTTPS وإدارة أسرار ونسخاً احتياطية ومراقبة.

## تنبيه مهم
DAKHIRTI هنا نموذج مدرسي تجريبي. جميع الأرصدة والتحويلات افتراضية، ولا يوجد اتصال بالبنوك أو خدمات الدفع. لا تستخدم بيانات مالية حقيقية.
لإطلاق خدمة تحويل أموال حقيقية، يلزم مزود دفع/مؤسسة مرخصة، ومراجعة قانونية، وبنية خادمية آمنة، ومصادقة متعددة العوامل، وحماية من الاحتيال واختبارات أمنية مستقلة.
